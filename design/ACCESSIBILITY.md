# Accessibility

**Status:** Decided (V4.1) · Part of the Wingman product & engineering spec.

Keyboard navigation, visible focus, sufficient contrast, ARIA roles/labels, alt text, reduce-motion support, and no
state-by-color-only. Timers combine text (MM:SS) + a linear bar + an optional single haptic at 30s so color-blind and
motion-sensitive users are never disadvantaged. Buttons have explicit labels; the selfie secondary action is a plain
"Let it expire", not an icon-only control.
