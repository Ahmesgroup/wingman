# Component Library

**Status:** Decided (V4.1) · Part of the Wingman product & engineering spec.

Shared `packages/ui` across mobile/web/admin: Button (primary/secondary/ghost/love), Card, BottomSheet, MoodDot,
RadarCanvas, Timer (text+bar), Badge, Switch, PillSet, ConsentItem, ChatBubble, TierCard, Toast. Each component reads
tokens from `design-tokens.json` and respects reduce-motion and focus states.
