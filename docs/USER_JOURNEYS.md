# User Journeys

**Status:** Decided (V4.1) · Part of the Wingman product & engineering spec.

## Primary: Radar → meeting
Activate Radar → set mood → tap an anonymous dot → Send a Signal → (peer opens) → initiator selfie → recipient
selfie → approve → Connection confirmed → Mission Meet (decide a place) → "Let's meet" → Mission Mode → outcome →
cooldown → back to Radar.

## Ticket branch
At mutual validation, if not able to meet now → hold a Connection Ticket (2h Free / 24h Wingman+) → one party
signals availability → other confirms → Mission Meet.

## Destiny branch (post-V1)
Repeated public crossings (both consented) → discreet prompt → Destiny Signal → standard protocol.

## Failure paths (all silent)
Signal ignored (10-min silent expiry); selfie window elapses; approval window elapses; Mission Meet expires. No
rejection is ever sent.

## Safety path
From Radar/selfie/Mission Meet, ≤2 taps to report+block → instant silent one-way block → evidence sealed only if
reported during a session.
