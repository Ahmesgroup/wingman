# Admin Product Spec

**Status:** Decided (V4.1) · Part of the Wingman product & engineering spec.

Next.js admin app for moderation, identity review, and privacy operations. Least-privilege roles; strong auth
(SSO+MFA). Surfaces: moderation queue, case detail (with audited evidence access), identity verification review,
privacy request handling, and KPIs. Never exposes raw phone, selfies, chat, or precise location without an audited,
authorized action.
