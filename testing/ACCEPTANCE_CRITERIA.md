# Acceptance Criteria

**Status:** Decided (V4.1) · Part of the Wingman product & engineering spec.

A feature is done when: PRD behavior matches; invariants enforced (with tests); silent-expiry preserved; timers
server-authoritative; idempotent; rate-limited; logs redacted; accessible (reduce-motion, labels, readable timer);
docs updated (PRD/DECISION_LOG/ADR/schema as applicable).
