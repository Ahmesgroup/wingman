# Prototype Screens

**Status:** Decided (V4.1) · Part of the Wingman product & engineering spec.

All 25 screens live in the single-page `../index.html` as `.view` sections toggled by `show(id)` in `../app.js`. This
folder documents the screen list for reference; there are no separate HTML files by design (open-and-run simplicity).
Screen ids: v-splash, v-onboard1..3, v-phone, v-otp, v-profile, v-consent, v-radar (invisible+active+mood+card),
v-signal, v-selfie, v-confirmed, v-ticket, v-mission-meet, v-mission-mode, v-outcome, v-cooldown, v-destiny, v-pulse,
v-settings, v-report, v-report-done, v-plan (dormant, no checkout), v-admin.
