# Data Processing Purposes

**Status:** Decided (V4.1) · Part of the Wingman product & engineering spec.

| Purpose | Basis | Data |
|---|---|---|
| Core matching / protocol | Contract | profile, signal/connection metadata |
| Approximate location (Radar) | Consent | coarse, ephemeral location |
| Destiny Connection | Consent | coarse co-presence (post-V1) |
| Push notifications | Consent | device token |
| Product analytics | Consent | aggregated, non-sensitive events |
| Safety / anti-abuse | Legitimate interest | blocks, reports, sealed evidence (on report) |
| Billing | Contract / legal | purchases, transactions |
