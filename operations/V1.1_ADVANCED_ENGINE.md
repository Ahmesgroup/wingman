# V1.1 Advanced Engine — Roadmap

**Status:** Active post–Backend V1 freeze · Related: [`S20_PRODUCTION_CERTIFICATION.md`](./S20_PRODUCTION_CERTIFICATION.md)

Wingman **Backend V1 is immutable**. New intelligence is added **above** V1 via separate packages, policies, and feature flags. Each sprint must be disableable without breaking V1.

| Sprint | Engine | Objective | Primary gate |
|--------|--------|-----------|--------------|
| **S21** | Radar Intelligence | Order eligible candidates contextually | Same candidates as V1; order improved & explainable — **done** |
| **S22** | Context Engine | Time/place/availability/language/mobility context | No exclusion on unreliable data — **done** |
| **S23** | Destiny V2 | Rare, controlled encounter opportunities | Never forced / repetitive / uncontrolled — **done** |
| **S24** | Anti-Abuse Engine | Spam, harassment, farming patterns | Gradual actions; no opaque auto-ban — **done** |
| **S25** | Geo Intelligence | Buckets, density, adaptive precision | Better relevance without exact location exposure — **done** |
| **S26** | Learning & Measurement | Measurable, auditable, reversible decisions | No auto-learning before measurement — **done** |
| **S24.1** | Destiny proposal persistence | Shared Redis/memory proposal store | Multi-instance consent without Postgres — **done** |

## Locked sequence (current)

```text
S21–S26 + S24.1 product/infra     DONE
Staging load certification        GO
Measurement instrumentation       DONE (v1.2.0)
        ↓
REAL BASELINE COLLECTION          ← NOW (MEASUREMENT=ON, LEARNING=OFF)
        ↓
S26 Review                        (evidence gate — required)
        ↓
A) no change  |  B) manual policy tune  |  C) S27 Adaptive only if justified
```

Live board: [`PROJECT_STATE.md`](./PROJECT_STATE.md).

| Step | Nature | Objective |
|------|--------|-----------|
| **S25** | Product (done) | Primitives only via port: `distanceBand`, `density`, `freshness`, `movement` — never long trajectories or exact coords; S21/S23 consume port; V1 eligibility unchanged |
| **Staging load** | Infra certification — **GO** | Shared Redis/Postgres concurrency. Certificate: [`STAGING_LOAD_CERTIFICATION.md`](./STAGING_LOAD_CERTIFICATION.md) |
| **Baseline collection** | Ops campaign (**now**) | `MEASUREMENT_ENABLED=true`, learning off — quality + safety + diversity + resilience together |
| **S26 Review** | Evidence gate | Compare V1/V1.1; no single North Star; decide A/B/C |
| **S27** | Optional only | Adaptive Engine **iff** Review option C — never automatic |

**No auto-learning now.** Without a real baseline + S26 Review we cannot tell useful adaptation from Signal-volume gaming.

### S26 baseline metrics (minimum)

| Metric | Status (v1.2.0) |
|--------|-----------------|
| Radar impression → Signal | Yes (`timeToSignal` via radar→signal latency) |
| Signal → mutual (connection) | Yes (`signalToConnectionRate`) |
| Mutual → Mission | Yes (`mission.entered` / `connectionToMissionRate`) |
| Mission → completed encounter | Yes (`mission.completed` / `missionCompletionRate`) |
| Time-to-signal | Yes (`baselines.timeToSignal`) |
| Repeat exposure rate | Yes (`radar.repeat_exposure` / `repeatExposureRate`) |
| Destiny acceptance rate | Yes (`destinyAcceptanceRate`) |
| Blocks after interaction | Partial (`blocksPerSignal`) |
| Anti-abuse sanctions | Yes (`abuseEnforced`) |
| Fallback when context/geo absent | Yes (`context.fallback` / `geo.fallback` / `fallbackShare`) |

Every advanced decision already carries `engine`, `version`, `decisionId`, internal reasons, timestamp + flag snapshot.

**Principle:** Measurement observes; it never decides. No auto-learning until baseline collection + quality/safety/diversity analysis.

### S25 hard rule (locked)

Geo exposes **classes only** through `GeoContextPort` / `GeoPairView`. No trajectory history, no lat/lng on the port. Adaptive radii are recommendations — never V1 eligibility.
